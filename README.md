# Guardian of the Fields 🌾

A 2D action/strategy game where players defend crops against incoming waves of threats using strategic abilities and mechanics.

## 🚀 Features

- **Strategic Defenses:** Manage abilities and resources to defend fields.
- **Custom Mechanics:** Custom ability timers and collision systems built in Godot.
- **Standalone Executable:** Optimized build bundled with Git LFS support.

## 🎮 How to Run

1. Download `guardian.exe` from the repository or Releases.
2. Double-click `guardian.exe` to launch the game.

## 🛠️ Built With

- **Game Engine:** [Godot Engine](https://godotengine.org/)
- **Version Control:** Git & Git LFS
